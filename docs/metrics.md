# Спецификация показателей

Все показатели ниже запланированы. Перед реализацией для каждого нужно зафиксировать источник и поле, формулу, гранулярность, единицу измерения, дату учёта и исключения. Формулы проверяются на контрольной выборке.

| Показатель | Что нужно определить |
| --- | --- |
| Заказы | Единицу счёта и ключ. Согласовать учёт отмен и дату оформления. |
| Продажи и возвраты | Событие учёта, идентификатор, количество единиц и правило связи возврата с продажей. |
| Выручка | Сумму и валюту, учёт скидок, возвратов и комиссий. Раздельно определить показатели продаж и финансовой реализации. |
| Средний чек | Числитель, единицу покупки в знаменателе и поведение при нулевом знаменателе. |
| Остатки | Товар, склад и момент снимка. Для ряда по датам выбрать правило последнего доступного снимка. |
| MoM | Отношение разницы между текущим и предыдущим месяцем к предыдущему значению. Согласовать обработку нулевой базы и неполного месяца. |
| ABC-анализ и эффективность SKU | Критерий сортировки, пороги накопленной доли, период и дополнительные показатели эффективности. |
