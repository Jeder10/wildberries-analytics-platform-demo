# Демонстрация Power BI

Откройте [Wildberries.pbip](../powerbi/Wildberries.pbip) в Power BI Desktop. Параметр `DemoMode` включён. Нажмите «Обновить», чтобы импортировать встроенные вымышленные данные. Проверьте, как фильтр по дате меняет дневные показатели и как в остатках разделены нулевое и неизвестное количество.

Отдельную демонстрационную копию можно создать командой `python -m src.report_demo` в версиях проекта с этим модулем. Она сохранится в локальном каталоге `data/`.
