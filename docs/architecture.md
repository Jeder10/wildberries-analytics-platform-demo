# Архитектура

Wildberries API → Python ETL → PostgreSQL → SQL-витрины → Power BI.

- Python проверяет конфигурацию и ответы API, управляет пагинацией и сохраняет данные в PostgreSQL.
- Таблицы `wb` хранят факты и прогресс выгрузки. Витрины `analytics` готовят ключи, даты и агрегаты для отчёта.
- Каталог использует артикул `nm_id`, заказы — `srid`, продажи и возвраты — `sale_id`. Финансовые строки идентифицируются по `rrd_id`.
- Строки страницы оперативной истории и её курсор фиксируются одной транзакцией. Повторный запуск читает сохранённое состояние.
- В отчёте по дням заказы относятся к дате оформления, продажи и возвраты — к дате операции. Воронка использует период оформления заказа.

Для проверки ключей, тайм-аутов, повторов и обработки ответов используйте тесты с синтетическими данными.
