# Технические решения

## PostgreSQL как основное хранилище

Для локального проекта выбран PostgreSQL. В нём планируется хранить исходные записи, историю загрузок и SQL-витрины. Транзакции и ограничения уникальности можно использовать при реализации повторяемых загрузок. Выбор пока подтверждён на уровне архитектуры и доступности клиента PostgreSQL 18.6. Проверка соединения и фактической нагрузки предстоит.

ClickHouse может понадобиться, если измерения покажут узкое место в аналитических запросах и отдельный движок оправдает сложность эксплуатации.

## Хранение конфигурации и данных

Версионируемый шаблон настроек расположен в [`.env.example`](../.env.example). [`.gitignore`](../.gitignore) исключает локальные настройки, типовые файлы выгрузок, резервные копии и файлы Power BI, которые могут содержать данные. Синтетические примеры будут добавляться после проверки происхождения и формата с узким исключением из правил при необходимости.
